### 🎵 Muse

A music streaming platform built as both **Spring Boot microservices** and a **Node.js/Express** monolith, paired with a React + Vite + Tailwind + GSAP frontend.

- Prisma/PostgreSQL data layer, JWT auth (httpOnly refresh + in-memory access token)
- Granular RBAC across admin / user / premium roles
- Cloudinary-hosted media, async email + in-app notifications

A free, ad-free calisthenics app — *"From Soft to Handcrafted."* Features a **dynamic 3D body avatar** that morphs from real user measurements, plus a structured progression-ladder training system.

- Firebase Firestore/Auth backend
- Dark-mode classical art aesthetic — bronze, marble, obsidian
